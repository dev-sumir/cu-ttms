# Timetable Automation System: Design System (Color & Typography)

## 1. Typography Selection
* **Headings:** `Montserrat` (Bold, geometric layout to mirror the strong institutional headers).
* **Body / Grid Data:** `Inter` (Highly legible sans-serif, optimized for dense timetable data and numbers).

## 2. Core Brand Palette (Extracted Reference)
* **Brand Red:** `#C41E22` (Derived from the primary logo box and footer block).
* **Brand Black:** `#1A1A1A` (Derived from the heavy main text).
* **Watermark Grey:** `#D1D5DB` (Derived from the background gear element).

## 3. Light Mode Scheme
* **Background:** `#FFFFFF` (Pure white)
* **Surface (Cards/Grids):** `#F9FAFB` (Subtle off-white for depth)
* **Primary Text:** `#111827` (Deep slate/black)
* **Secondary Text:** `#6B7280` (Muted grey for sub-labels)
* **Primary Accent (Buttons/Active):** `#C41E22` (Brand Red)
* **Borders & Dividers:** `#E5E7EB`

## 4. Dark Mode Scheme
* **Background:** `#09090B` (Deep black/slate)
* **Surface (Cards/Grids):** `#18181B` (Elevated dark grey)
* **Primary Text:** `#FAFAFA` (Clean off-white)
* **Secondary Text:** `#A1A1AA` (Muted light grey)
* **Primary Accent (Buttons/Active):** `#E11D48` (Slightly brightened red for accessibility and contrast on dark backgrounds)
* **Borders & Dividers:** `#27272A`
